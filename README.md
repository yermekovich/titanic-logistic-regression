# Titanic: логистическая регрессия с расширенным EDA

Предсказание выживания пассажиров Титаника: расширенный EDA, предобработка, создание новых признаков, подбор гиперпараметров через GridSearchCV.

## Результаты
- Лучший ROC-AUC на кросс-валидации: **0.861**
- На отложенной выборке (179 пассажиров): **accuracy 0.805, ROC-AUC 0.862**

## Запуск
Откройте `practice.ipynb` в Jupyter. Зависимости: pandas, numpy, scikit-learn, matplotlib, seaborn.
